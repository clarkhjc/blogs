# 一、音频基本概念

**PCM**：脉冲编码调制（Pulse Code Modulation, PCM）是一种模拟信号的数字化方法。它是最常用、最简单的波形编码方式。

**采样率**：即每秒内进行采样的次数。符号是fs，单位是Hz。采样率越高，数字波形的形状就越接近原始模拟波形，声音的还原就越真实。

**采样位数**：字面意义就是采样值的二进制编码的位数。采样位数反应了采样系统对声音的辨析度，位数越高，对声音的记录就越精细，所以也称之为采样精度，采样深度。

**声道**：是指声音在录制或播放时在不同空间位置采集或回放的相互独立的音频信号。

常见的声道数有单声道（Mono），双声道（即立体声，Stereo），5.1声道，7.1声道等。

**比特率**：就是指每秒传送或处理的比特的数量（位数），也称为码率。

# 二、ffmpeg命令行输出、输入pcm文件

1. 输出pcm文件

```
ffmpeg -i in.mp4 -vn -ac 2 -ar 44100 -f s16le out.pcm
```
-vn表示丢弃视频轨道

-ac表示输出声道数

-ar表示输出采样率

-f s16le表示输出采样位数，位数是有符号16bit，小端存储。

通过下面命令可以得到ffmpeg支持的所有采样位数:
```
ffmpeg -formats | grep PCM
```
![ffmpeg支持的pcm格式](ffmpeg支持的pcm格式.png)

2. 输入pcm文件

```
ffmpeg -ac 2 -ar 44100 -f s16le -i in.pcm -c:a aac out.aac
```
此命令将pcm编码为aac文件。

3. pcm播放

可以下载开源工具[Audacity](https://www.audacityteam.org/download/)播放pcm原始文件。

通过“文件”->“导入”->“原始数据”来打开pcm文件，在弹出的“导入原始数据”对话框中，需要手动选择编码、字节序、声道、采样率：
![手动选择音频参数](手动选择音频参数.png)

点击“导入”:
![audacity播放界面](audacity播放界面.png)

点击左上角的播放按钮，即可播放pcm文件。
