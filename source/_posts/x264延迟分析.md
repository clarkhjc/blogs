x264提供了两个函数来获取内部缓存的帧数
```c
int x264_encoder_delayed_frames(x264_t *h)
int x264_encoder_maximum_delayed_frames(x264_t *h)
```

x264_encoder_maximum_delayed_frames返回x264可能缓存的最大帧数
```c
int x264_encoder_maximum_delayed_frames( x264_t *h )
{
    return h->frames.i_delay;
}
```

`h->frames.i_delay`受多个参数影响
```c
if( h->param.i_bframe_adaptive == X264_B_ADAPT_TRELLIS && !h->param.rc.b_stat_read )
    h->frames.i_delay = X264_MAX(h->param.i_bframe,3)*4;
else
    h->frames.i_delay = h->param.i_bframe;
if( h->param.rc.b_mb_tree || h->param.rc.i_vbv_buffer_size )
    h->frames.i_delay = X264_MAX( h->frames.i_delay, h->param.rc.i_lookahead );
i_slicetype_length = h->frames.i_delay;
h->frames.i_delay += h->i_thread_frames - 1;
h->frames.i_delay += h->param.i_sync_lookahead;
h->frames.i_delay += h->param.b_vfr_input;
```
延迟受B帧数、lookahead数、帧线程数、sync_lookahead数、b_vfr_input五个参数影响。
B帧数默认为3
lookahead默认为40
帧线程数默认为cpu核数的1.5倍
sync_lookahead默认为B帧数加1
b_vfr_input通常为0

在8核处理器上，默认参数的情况下，最大延迟为max(3, 40) + (12 - 1) + 4 + 0 = 55

## 低延迟编码
将tune设置为zerolatency
```shell
x264 --input-res 1280x720 --tune zerolatency -o out.h264 720p.yuv
```

低延迟会自动设置下面这些参数
```c
param->rc.i_lookahead = 0;
param->i_sync_lookahead = 0;
param->i_bframe = 0;
param->b_sliced_threads = 1;
param->b_vfr_input = 0;
param->rc.b_mb_tree = 0;
```
主动将B帧数、lookahead数、sync_lookahead数、b_vfr_input设置为0
另外如果开启了slice线程，帧线程数会设置为1，所以最大延迟为0了！
