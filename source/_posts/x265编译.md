# 下载x265

```shell
git clone https://bitbucket.org/multicoreware/x265_git.git
```

x265使用cmake编译，所以编译之前要保证系统安装了cmake.

# ubuntu下编译x265

进入目录 `x265_git/build/linux`

## 常用选项

```shell
-CMAKE_BUILD_TYPE=Debug   //编译debug版本
-CMAKE_BUILD_TYPE=Release //编译release版本

-ENABLE_SHARED=ON  //编译动态库
-ENABLE_SHARED=OFF //不编译动态库

-HIGH_BIT_DEPTH=ON  //支持8/10bit
-HIGH_BIT_DEPTH=OFF //只支持8bit

-CMAKE_INSTALL_PREFIX=xx //安装路径前缀
```

选项在使用时需要加-D前缀，形如:-D`<var>`=`<val>`

1. 编译release版本的静态库，支持高bit位深，安装到/home/x265目录下

```shell
cmake -G "Unix Makefiles" -DCMAKE_BUILD_TYPE=Release -DENABLE_SHARED=OFF -DHIGH_BIT_DEPTH=ON -DCMAKE_INSTALL_PREFIX=/home/x265/ ../../source/

make -j4
```

# 集成到ffmpeg中

ffmpeg配置选项如下：

```shell
./configure --enable-gpl --enable-libx265 --pkg-config-flags=--static
```

一定要加上 `--pkg-config-flags=--static`否则会报错!

x265是c++代码编写的，在链接时需要链接stdc++库，x265.pc在Libs.private中指定了`-lstdc++`，默认是不链接Libs.private，
只有在对pkg-config指定了`--static`选项时才会链接Libs.private中的库。

pkg-config帮助文档中关于static选项的描述:
>static: 
>  Output libraries suitable for static linking.  That means including any private libraries in the output.  This relies on proper tagging in the .pc files, else a too >  large number of libraries will ordinarily be output.
